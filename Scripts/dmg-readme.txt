Dockside — public beta

INSTALL
1. Drag Dockside into the Applications folder in this window.
2. Open Dockside from Applications.

IF macOS SAYS IT "CAN'T BE OPENED" OR "COULD NOT VERIFY" DOCKSIDE
Dockside is free and open source, and this beta isn't notarized by Apple yet, so
macOS asks you to confirm the first launch:

  1. Try to open Dockside once, then click Done (or OK).
  2. Open System Settings ▸ Privacy & Security.
  3. Scroll down and click "Open Anyway" next to the Dockside message.
  4. Confirm with your password or Touch ID.

Prefer the Terminal? This does the same thing:
  xattr -dr com.apple.quarantine /Applications/Dockside.app

You can read every line of the source and build it yourself:
https://github.com/shreyansa98/Dockside

GETTING STARTED
- Push your pointer against the bottom edge of the screen to reveal Dockside.
- ⌃⌥D keeps it open. ⌃⌥C opens Claude.
- The dock icon in the menu bar has Settings, profiles and Quit.
